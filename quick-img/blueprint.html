quick-img 架构蓝图

版本 1.1.0 | DMX Gemini 3.1 Flash Image Preview | 生成高质量图片
三种使用模式
Direct Prompt

提示词直出

直接输入提示词生成图片，最常用模式，零配置。

适用场景：自由创作、概念图、快速生图、思源笔记内容生图

python scripts/generate_image.py --prompt "AI 概念艺术" --ratio 16:9 --size 2K
Template

模板生成

读取文件内容，套用生图模板后生成信息图。

适用场景：Markdown 文档转配图、日报信息图

python scripts/generate_image.py --input article.md --ratio 4:5 --size 2K
Refine

精炼后生图

长内容先提炼，展示精炼结果，确认后再生成。

适用场景：内容过长、需要提炼核心信息

Claude 行为层处理，无额外参数

SiYuan 笔记集成
1

读取笔记内容

通过 SiYuan MCP 搜索并获取笔记内容

mcp__siyuan__search(action="fulltext", query="笔记标题")
2

选择模式

短内容 → Direct Prompt 直接生图

长内容 → Refine 模式先精炼

3

生成图片

调用 generate_image.py 生成图片

python scripts/generate_image.py --prompt "笔记内容" --ratio 4:5 --size 2K
API 特性

图片搜索（Image Search）

启用图片搜索，让模型参考真实图片生成

参数：--image-search

场景：需要参考特定风格、真实物体或场景时开启

注意：会增加生成时间，但能提升特定场景的真实度

Google 搜索

启用 Google 搜索获取实时信息

参数：--google-search

场景：需要最新信息或特定知识时开启
