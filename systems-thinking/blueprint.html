系统循环图语法
// 基础连接语法 [变量A] --S--> [变量B] // 同向变化（A↑ → B↑） [变量A] --O--> [变量B] // 反向变化（A↑ → B↓） [变量A] --S(时滞)--> [变量B] // 存在时间延迟 // 增强回路示例 R1: [压力] --S--> [加班] --S--> [疲劳] --O--> [效率] --O--> [压力] 【增强回路 — 恶性循环】 // 调节回路示例 B1: [目标] --S--> [差距] --S--> [行动] --S--> [实际] --O--> [差距] 【调节回路 — 趋向目标】
S型连接：同向
O型连接：反向
偶O增强 增强回路
奇O调节 调节回路

思维陷阱分类
认知偏差类
线性思维 — 忽略反馈回路
过度简化 — 遗漏关键因素
单一视角 — 只从一个角度看
静态思维 — 只看快照不看演变
行为模式类
时滞忽视 — 期待立竿见影
猛踩油门 — 强行推动增强回路
症状解陷阱 — 只处理表面症状
行动偏见 — 害怕什么都不做
分析工具类
爱上图表 — 拒绝修改
数据迷信 — 忽视模糊变量
快速判断 — 过早下结论
工具误用 — 机械套用原型
系统边界类
局部最优 — 优化局部损害整体
边界错误 — 范围太窄或太宽
归因错误 — 归因个人忽略系统
方法论基础
三大支柱
整体视角 + 反馈驱动 + 因果连接
杠杆解哲学
不要猛踩油门，松开刹车就够了
采访者角色
通过提问引导用户自己发现系统结构
增强回路 (R)
偶数个O → 指数增长/衰退
调节回路 (B)
奇数个O → 趋向目标，可能振荡
成长上限
增强回路 + 调节回路组合
模糊变量
难以量化但真实存在，使用定性描述
时滞
因果间的时间延迟，需要耐心
悬摆
系统边界外的输入/输出变量
12条黄金法则
1. 了解问题的边界
2. 从有趣的地方开始
3. 询问驱动和被驱动
4. 不要陷入混乱
5. 不要使用动词，请使用名词
6. 不要使用"在...方面增长/降低"
7. 不要害怕模糊变量
8. 及时确定连接类型（S/O）
9. 坚持就是胜利
10. 好图表必须反映实况
11. 不要爱上你的图表
12. 没有"已经完成"的图表
